# Exact four-coefficient terminal collision at the sharp maximum-weight threshold

*Research candidate, November 6, 2026. Mathematical novelty not established.*

## Statement and evidence

Let `u_a` be the integer signed multiplicities generated by the
reproducible pipeline below, for `1 <= a <= 1692`. The nonzero vector
has **587** signed entries and satisfies, by exact Legendre valuations,

```
sum_a a*u_a = 0
sum_a u_a * v_p((m*a)!) = 0
    for every prime p <= 4*1692 and m in {1,2,3,4}.
```

Its positive and negative multisets therefore have the same total weight,
and their factorial denominator products agree for the first four
supported coefficients. The fifth coefficient differs: exact evaluation
finds nonzero valuation differences for **318 distinct primes** at m=5.
This is an actual integer relation, not just a dependency over a finite
field.

The old common total weight is

```
9161682624469356243039134091379944310083
```

and the unpadded weight counts are

```
A: 27990950556264851229047371917314026508
B: 27991392711556946301081239744549080694
```

Appending 3384 (=2*1692) copies of weight 1 to **both** lists makes
both weighted projective spaces well-formed and terminal by the
terminal-padding lemma in `research/K3_SHARP_WEIGHT_THRESHOLDS.md`.
The result has total weight

```
9161682624469356243039134091379944313467
```

and dimensions

```
A: 27990950556264851229047371917314029891
B: 27991392711556946301081239744549084077
```

The two dimensions are **different**, so the resulting varieties are
nonisomorphic; their first four supported regularized quantum-period
coefficients agree exactly and their fifth supported coefficients differ.

## Sharpness is about largest individual weight, not total weight

The separate `scripts/verify_k4_rank.cpp` computes full column rank
**1691** for the first-four-coefficient valuation matrix restricted
to weights 1,...,1691, over the prime field F_65521. This certifies
full rank over Q, excluding any nontrivial common-total-weight relation
supported on these weights.

The explicit integral relation supported on weights through 1692
proves the bound **sharp**. Thus 1692 is the *smallest possible largest
individual weight* for a four-supported-coefficient collision within
the factorial-ratio weighted-projective class, even before imposing
terminality. The terminal construction above attains that threshold.

It is **not** claimed to minimize the total weight, number of weights,
dimension, or complexity of the varieties.

## Independent replay

```sh
g++ -std=c++20 -O3 -Wall -Wextra \
  -o /tmp/extract_k4_mod scripts/extract_k4_mod.cpp

mkdir -p /tmp/k4
for p in 1000000007 1000000009 1000000021 1000000033 \
         1000000087 1000000093 1000000097 1000000103 \
         1000000123 1000000181 1000000207 1000000223 \
         1000000241 1000000271 1000000289; do
   /tmp/extract_k4_mod "$p" > "/tmp/k4/residue_${p}.txt"
done

python scripts/reconstruct_k4.py /tmp/k4
```

The modular extractor computes a kernel vector independently at each
prime. Rational reconstruction combines the residues by CRT, clears
all denominators, reduces by the integer gcd, and then checks the
resulting integer identities prime by prime for m=1,2,3,4,5.
It rejects the putative witness if *any* supported factorial equality
fails at m<=4 or the fifth coefficient unexpectedly agrees.

GitHub Actions job `four-prefix-exact-collision` runs this
end-to-end pipeline from a fresh checkout and uploads the
full signed witness as a machine-readable JSON artifact. The artifact
is a verified computation receipt, not an assistant-typed list.

## Interpretation

This answers the concrete existence question for matching four supported
coefficients and *different dimensions*, within the terminal
well-formed weighted-projective family. It does **not** refute
infinite-period dimension reconstruction, identify arbitrary Fano
varieties, or establish the priority of the construction.
A much smaller four-coefficient collision may exist if one
allows individual weights above 1692; the rank threshold makes
no optimization claim about the total sum or geometric dimension.

The next useful research program is to search higher-dimensional
relation lattices for much smaller **total weight and multiplicity**,
with independent exact replay, and to attempt a five-coefficient
construction and corresponding maximal-weight obstruction.
